# PC-Training

Nachgebauter Windows-11-Desktop zum Üben der PC-Grundlagen: Maus, Ordner anlegen, Ausschneiden/Einfügen, Papierkorb, Fenster.
Statische PWA, kein Build-Schritt.

## Deploy (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
URL: https://peichhorndev.github.io/pc-training/

## Installieren
URL in Chrome/Edge öffnen → Installieren-Symbol rechts in der Adressleiste.

## Updates
Bei jeder Änderung `VERSION` in `sw.js` hochzählen.
